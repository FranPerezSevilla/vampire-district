# Intro concept reference sheet

`intro-reference-sheet.jpg` is a compact visual index of the approved/current intro directions. It is intentionally a lightweight review artifact rather than a production texture atlas.

Reading left-to-right, top row then bottom row:

1. Blood / power / control / destiny — pale vampire hand and glass.
2. Conversion — centered bite/conversion; vampire pale, convert warmer.
3. Return — protagonist silhouette against the city.
4. Loss — family photograph in an empty interior; no city through the window.
5. The Sire — no crown; pale vampire complexion.
6. Dependence — protagonist feeding; pale vampire complexion.
7. Closing — pale vampire protagonist smoking at night.
8. Official title wordmark — condensed block `VICEBLOOD` identity.

`title-wordmark-reference.jpg` is kept separately because the title treatment is a hard branding constraint, not merely mood reference.

For all implementation decisions, `../README.md` is authoritative over the thumbnails.
